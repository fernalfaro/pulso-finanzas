# Pulso Finanzas

Tablero interactivo para registrar y analizar ingresos y gastos de forma simple.

## Funciones

- Indicadores de balance, ingresos, gastos y tasa de ahorro.
- Gráfico de evolución mensual y distribución por categorías.
- Alta, edición y eliminación de movimientos.
- Búsqueda y filtros por mes, tipo y categoría.
- Exportación de movimientos a CSV.
- Persistencia local, tema claro/oscuro y diseño responsive.

Proyecto demostrativo creado con HTML, CSS, JavaScript y asistencia de inteligencia artificial.
